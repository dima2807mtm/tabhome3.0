КАК ПОЛУЧИТЬ APK ВАШЕГО ЭКРАНА (бесплатно, через GitHub, без Android Studio)
=============================================================================

Делаем так же, как уже делали с Wink Home для ТВ.

1. На https://github.com -> New repository. Название любое (например tabhome),
   видимость Private -> Create repository.
2. На странице репозитория: "uploading an existing file" -> перетащите ВСЁ
   СОДЕРЖИМОЕ этой папки: settings.gradle, build.gradle, gradle.properties,
   папки app и .github (именно содержимое, а не саму папку launcher-project).
   Если папка .github не перетащилась (так уже было один раз) - Add file ->
   Create new file -> в имени впишите .github/workflows/build.yml -> вставьте
   содержимое файла build.yml из этой папки -> Commit changes.
3. Вкладка Actions -> если не пошло само, build-apk -> Run workflow.
   3-6 минут до зелёной галочки.
4. Открыть запуск -> Artifacts внизу -> скачать tabhome-apk (это zip).
5. Распаковать, получить tabhome.apk, положить в папку xiaomi-tablet-toolkit
   рядом со скриптами (где 01-connect.cmd и т.д.) -> запустить 05-install-launcher.cmd.

Что делает этот экран (версия 2.0)
  * Фон - фото природы (12 штук, раз в 20 минут плавно меняются, медленно
    "дышат" приближением; интернет не нужен). Экран без серых полос сверху
    и снизу - на всю площадь.
  * Слева вверху - приветствие, крупные часы и дата.
  * Внизу по центру - плавающий док без рамок: Иви, Кинопоиск, Chrome.
    Иконки нарисованы специально для этого экрана (цветные плитки с мягкой
    тенью), а не берутся из приложений. Нажали - откроется настоящее
    приложение. Если приложения нет на планшете - иконка приглушена, а при
    нажатии подскажет поставить его через HyperOS.
  * Справа вверху - кнопка-замок. Первый раз попросит придумать и повторить
    4-значный PIN, дальше - спросит PIN на полном экране с цифровой
    клавиатурой. Неверный PIN - точки трясутся; 5 ошибок подряд - пауза 30 с.
  * Верный PIN открывает рабочий стол HyperOS (этот экран остаётся главным -
    после Home вы снова на нём). Если система не даст открыть HyperOS
    напрямую, появится окно с подсказкой и кнопкой "Выбрать рабочий стол"
    (тогда выберите HyperOS один раз; чтобы вернуть этот экран - нажмите Home
    и выберите "Мой экран" -> "Всегда").
  * Анимации: часы и док плавно "собираются" при каждом включении экрана,
    иконки пружинят под пальцем, PIN-экран выезжает снизу, точки пульсируют.
  * Поменять набор приложений - напишите мне, какие нужны: правится список
    APPS в HomeActivity.java, пересборка те же 3-6 минут через Actions.
  * PIN хранится только на самом планшете. Если забудется - Настройки ->
    Приложения -> "Мой экран" -> Очистить данные сбросит PIN.
  * Важно: если новая сборка подписана иначе, чем старая, 05-install-launcher.cmd
    сам удалит старую версию и поставит новую - PIN при этом придётся задать
    заново.
